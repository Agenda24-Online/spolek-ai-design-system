# Spolek.ai Design System & Brand Operating System

Živý modulární web pro GitHub Pages.

## Publikace
1. Nahrajte obsah této složky do kořene repozitáře.
2. Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /(root).
5. Uložte.

Adresa: https://agenda24-online.github.io/spolek-ai-design-system/

## Rozšiřování
- Nová sekce = nová složka s index.html.
- Odkaz přidat do data/navigation.json.
- Sdílený vzhled: css/main.css.
- Sdílené funkce: js/app.js.
- Grafiky: assets/.
