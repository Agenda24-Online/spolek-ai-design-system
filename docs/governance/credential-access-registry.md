# Registr přístupů Spolek.ai

- **Klasifikace:** Public / bez tajných údajů
- **Účel:** Bezpečný rozcestník k externě spravovaným přístupům
- **Aktualizace:** 30. 7. 2026

## Bezpečnostní pravidlo

Tento veřejný repozitář ani GitHub Pages nesmí obsahovat hesla, obnovovací kódy, API klíče, telefonní čísla používaná k ověření ani jiné autentizační údaje.

Úplné přístupy jsou uloženy pouze v externím správci hesel v kolekci **Spolek.ai**. Do repozitáře se zapisují pouze názvy položek, aby je oprávněný člen týmu dokázal ve správci hesel vyhledat.

| Služba | Název položky v externím správci hesel |
|---|---|
| WordPress | `Spolek.ai / WordPress / Administrace` |
| Firemní e-mail | `Spolek.ai / E-mail / info` |
| LinkedIn | `Spolek.ai / Social / LinkedIn` |
| X | `Spolek.ai / Social / X` |
| Facebook | `Spolek.ai / Social / Facebook` |
| Instagram | `Spolek.ai / Social / Instagram` |
| TikTok | `Spolek.ai / Social / TikTok` |

## Provozní pravidla

1. Skutečná hesla se nikdy nezapisují do repozitáře, issues, pull requestů, klientského JavaScriptu ani veřejných dokumentů.
2. Každý účet má mít unikátní heslo a zapnuté vícefaktorové ověření.
3. Po sdílení hesla v chatu nebo e-mailu se heslo považuje za kompromitované a musí být změněno.
4. Přístup se předává pomocí bezpečného sdílení ve správci hesel, nikoli kopírováním hesla.
